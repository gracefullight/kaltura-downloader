# Suggested Commands
Run from repository root unless noted.
- Install: `bun install`
- Watch all workspaces: `bun run dev`
- Build all workspaces: `bun run build`
- Test all workspaces: `bun run test`
- Lint: `bun run lint`
- Format: `bun run format`
- Extension-only build: `bun --filter @kaltura-downloader/ext build`
- Extension-only tests: `bun --filter @kaltura-downloader/ext test`
- Inspect working tree: `git status --short`
- Serena memory integrity: `serena memories check`
